# CodeAlpha_Credit_Scoring_Model
A Machine Learning project that predicts credit risk using financial and personal data with a Random Forest classifier.
## Project Overview
This project develops a Machine Learning model to predict credit risk using historical financial and personal data.

## Objective
To predict an individual's creditworthiness using classification techniques.

## Technology Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Model
Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## Dataset
German Credit dataset containing financial and personal information used for credit risk prediction.

## Internship
This project was completed as part of the CodeAlpha Machine Learning Internship.
